Sicherung

backup

Komplettsicherung der gesamten Datenbank (alle Vereine, Benutzer, Turniere, Urkunden-Vorlagen …) als Datei und Wiedereinspielen. Nur für Super-Admins; jede Aktion braucht den aktuellen Code Ihrer Authenticator-App (oder einen Backup-Code). Die Datei enthält Personendaten und Passwort-Prüfwerte: sicher aufbewahren.

Bestätigung

Ein Code gilt nur einmal: vor der nächsten Aktion bitte den nächsten Code der App abwarten (etwa 30 Sekunden).

Automatische Sicherung

Wird geladen …

Eingestellt wird sie in der .env des Servers: SICHERUNG_PASSWORT (verschlüsselt jede Sicherung, mindestens 20 Zeichen; oder SICHERUNG_PASSWORT_DATEI), SICHERUNG_UHRZEIT, SICHERUNG_BEHALTEN, SICHERUNG_AUTOMATISCH=false zum Abschalten. Eine Kopie an einem anderen Ort legen Sie mit SICHERUNG_KOPIE_VERZEICHNIS (z. B. ein eingehängtes Netzlaufwerk) oder SICHERUNG_NACH_BEFEHL (z. B. rclone copy "$HAJIME_SICHERUNG_DATEI" speicher:hajime) fest. Der Probelauf prüft Kopie und Befehl sofort.

Sichern

Auf dem Server abgelegte Sicherungen liegen im Verzeichnis – (die neuesten 30 bleiben erhalten). Für regelmäßige Sicherungen: node scripts/sicherung.mjs sichern per Cron.

Wiedereinspielen

Ersetzt alle Daten der Plattform durch den Stand der Sicherung. Neuere Daten gehen verloren. Vorher wird automatisch der aktuelle Stand auf dem Server gesichert (vor-wiederherstellung-…). Die Sicherung muss zur selben Programmversion gehören.
